  ### Building and Running

  1. Host Verification Harness (compiled and tested with GCC):
    cd src
    make
    make run

      • Output verifies the 1 MB ROM checksum (0xF1ACAD13), tests 68040 CPU detection and MMU transparent translation configuration, sizes RAM, validates low-memory
      globals, decompresses and resolves the complete 1,280 trap table, parses NuBus Declaration ROM structures, and executes Memory Manager / QuickDraw calls.
  2. Bare-Metal 68040 Assembly Build:
    cd src
    make m68k

      • Assembles reset.s and trap_dispatcher.s directly targeting the Motorola 68040 processor.
